# Email Spam Detection System

A machine learning system to classify emails as spam or ham with over 90% accuracy.

## Features
- Text preprocessing (cleaning, tokenization, stemming)
- TF-IDF vectorization for feature extraction
- Multiple ML models (Naive Bayes, SVM, Logistic Regression, Random Forest)
- Web interface for easy predictions
- REST API for integration
- Model evaluation with comprehensive metrics
